# Список тестов лексера Lait

## Идентификаторы и ключевые слова

- [x] Разбор идентификаторов из одной и нескольких букв: `x value userName`
- [x] Разбор идентификаторов с цифрами и символом подчёркивания после первой буквы: `value2 Point2D read_value`
- [x] Учёт регистра в идентификаторах: `value Value VALUE`
- [x] Разбор всех ключевых слов: `bool else false func if int new return string struct true void while`
- [x] Учёт регистра в ключевых словах: `Bool If TRUE While` распознаются как идентификаторы
- [x] Имена `main`, `print`, `readInt` и `readString` распознаются как идентификаторы
- [x] Символ `_` в начале `_value` вызывает лексическую ошибку и не включается в идентификатор `value`
- [x] Символы вне латинского алфавита в записи `имя` вызывают лексические ошибки

## Целочисленные литералы

- [ ] Разбор нуля: `0`
- [ ] Разбор положительных целых чисел: `7 1250`
- [ ] Разбор максимального допустимого значения: `2147483647`
- [ ] Знак минуса распознаётся отдельно от числа: `-15`
- [ ] Ошибка при ведущем нуле: вся последовательность `00` или `007` считается одной ошибочной лексемой
- [ ] Ошибка при выходе за допустимый диапазон: `2147483648`

## Строковые литералы

- [ ] Разбор пустой и обычной строк: `"" "Lait"`
- [ ] Разбор строки с символами Unicode: `"Привет, Lait!"`
- [ ] Разбор escape-последовательности переноса строки: `"First line\nSecond line"`
- [ ] Разбор escape-последовательности табуляции: `"a\tb"`
- [ ] Разбор экранированной двойной кавычки: `"Say \"Hello\""`
- [ ] Разбор экранированной обратной косой черты: `"C:\\code"`
- [ ] Последовательности `//`, `/*` и `*/` внутри строки не считаются комментариями
- [ ] Ошибка при неизвестной escape-последовательности: `"\q"`
- [ ] Ошибка при незавершённом строковом литерале: `"Lait`
- [ ] Ошибка при обычном переносе строки внутри строкового литерала
- [ ] Ошибка при непечатном управляющем символе внутри строкового литерала

## Операторы

- [ ] Арифметические операторы: `+ - * /`
- [ ] Присваивание и проверка равенства: `= ==`
- [ ] Операторы неравенства и отрицания: `!= !`
- [ ] Операторы сравнения: `< <= > >=`
- [ ] Логические операторы: `&& ||`
- [ ] Оператор доступа к полю: `.`
- [ ] Выбор самой длинной лексемы для операторов без пробелов: `===` разбирается как `==` и `=`, `!==` - как `!=` и `=`, `<<=` - как `<` и `<=`

## Скобки и разделители

- [ ] Круглые скобки: `(` и `)`
- [ ] Фигурные скобки: `{` и `}`
- [ ] Квадратные скобки: `[` и `]`
- [ ] Разделители: `, : ;`

## Пробельные символы

- [x] Пропуск обычного пробела: `" "`
- [x] Пропуск горизонтальной табуляции: `\t`
- [x] Пропуск переноса строки: `\n`
- [x] Пропуск возврата каретки: `\r`
- [x] Пропуск нескольких разных пробельных символов между токенами
- [ ] Разбор соседних токенов, которым не требуется пробел: `value=10;`

## Комментарии

- [ ] Пропуск однострочного комментария до переноса строки
- [ ] Пропуск однострочного комментария до конца файла
- [ ] Пропуск пустого однострочного комментария: `//`
- [ ] Пропуск многострочного комментария в одной строке: `/* comment */`
- [ ] Пропуск многострочного комментария с переносами строк
- [ ] Многострочный комментарий заканчивается ближайшей последовательностью `*/`
- [ ] Пропуск нескольких комментариев и пробельных символов подряд
- [ ] Различение оператора деления `/` и начала комментариев `//`, `/*`
- [ ] В записи `/* outer /* inner */ value` комментарий заканчивается на первом `*/`, после чего распознаётся идентификатор `value`
- [ ] Ошибка при незавершённом многострочном комментарии

## Ошибки и конец файла

- [x] Ошибка при неизвестном символе
- [x] Пустой исходный текст сразу возвращает конец файла
- [x] Текст только из пробельных символов сразу возвращает конец файла
- [ ] Текст только из комментариев сразу возвращает конец файла
- [x] После последней лексемы возвращается токен конца файла

- [ ] Все сложные случаи идентификаторов и строковых литералов покрыты тестами
- [ ] Все виды комментариев и пробельных символов покрыты тестами
- [ ] Все положительные, граничные и ошибочные случаи проходят
- [ ] Покрытие кода лексера составляет не менее 90%
- [ ] Проект собирается без ошибок и предупреждений
- [ ] Тесты проходят в Windows и Linux
