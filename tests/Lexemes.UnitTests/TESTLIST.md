# Список тестов лексера Lait

## Идентификаторы и ключевые слова

- [x] Разбор идентификаторов из одной и нескольких букв: `x value userName`
- [x] Разбор идентификаторов с цифрами и символом подчёркивания после первой буквы: `value2 Point2D read_value`
- [x] Учёт регистра в идентификаторах: `value Value VALUE`
- [x] Разбор всех ключевых слов: `bool else false func if int new return string struct true void while`
- [x] Учёт регистра в ключевых словах: `Bool If TRUE While` распознаются как идентификаторы
- [x] Имена `main`, `print`, `readInt` и `readString` распознаются как идентификаторы
- [x] Символ `_` в начале `_value` вызывает лексическую ошибку и не включается в идентификатор `value`
- [x] Символы вне латинского алфавита в записи `имя` вызывают лексические ошибки

## Целочисленные литералы

- [x] Разбор нуля: `0`
- [x] Разбор положительных целых чисел: `7 1250`
- [x] Разбор максимального допустимого значения: `2147483647`
- [x] Знак минуса распознаётся отдельно от числа: `-15`
- [x] Ошибка при ведущем нуле: вся последовательность `00` или `007` считается одной ошибочной лексемой
- [x] Ошибка при выходе за допустимый диапазон: `2147483648`

## Строковые литералы

- [x] Разбор пустой и обычной строк: `"" "Lait"`
- [x] Разбор строки с символами Unicode: `"Привет, Lait!"`
- [x] Разбор escape-последовательности переноса строки: `"First line\nSecond line"`
- [x] Разбор escape-последовательности табуляции: `"a\tb"`
- [x] Разбор экранированной двойной кавычки: `"Say \"Hello\""`
- [x] Разбор экранированной обратной косой черты: `"C:\\code"`
- [x] Последовательности `//`, `/*` и `*/` внутри строки не считаются комментариями
- [x] Ошибка при неизвестной escape-последовательности: `"\q"`
- [x] Ошибка при незавершённом строковом литерале: `"Lait`
- [x] Ошибка при обычном переносе строки внутри строкового литерала
- [x] Ошибка при непечатном управляющем символе внутри строкового литерала

## Операторы

- [x] Арифметические операторы: `+ - * /`
- [x] Присваивание и проверка равенства: `= ==`
- [x] Операторы неравенства и отрицания: `!= !`
- [x] Операторы сравнения: `< <= > >=`
- [x] Логические операторы: `&& ||`
- [x] Оператор доступа к полю: `.`
- [x] Выбор самой длинной лексемы для операторов без пробелов: `===` разбирается как `==` и `=`, `!==` - как `!=` и `=`, `<<=` - как `<` и `<=`

## Скобки и разделители

- [x] Круглые скобки: `(` и `)`
- [x] Фигурные скобки: `{` и `}`
- [x] Квадратные скобки: `[` и `]`
- [x] Разделители: `, : ;`

## Пробельные символы

- [x] Пропуск обычного пробела: `" "`
- [x] Пропуск горизонтальной табуляции: `\t`
- [x] Пропуск переноса строки: `\n`
- [x] Пропуск возврата каретки: `\r`
- [x] Пропуск нескольких разных пробельных символов между токенами
- [x] Разбор соседних токенов, которым не требуется пробел: `value=10;`

## Комментарии

- [x] Пропуск однострочного комментария до переноса строки
- [x] Пропуск однострочного комментария до конца файла
- [x] Пропуск пустого однострочного комментария: `//`
- [x] Пропуск многострочного комментария в одной строке: `/* comment */`
- [x] Пропуск многострочного комментария с переносами строк
- [x] Многострочный комментарий заканчивается ближайшей последовательностью `*/`
- [x] Пропуск нескольких комментариев и пробельных символов подряд
- [x] Различение оператора деления `/` и начала комментариев `//`, `/*`
- [x] В записи `/* outer /* inner */ value` комментарий заканчивается на первом `*/`, после чего распознаётся идентификатор `value`
- [x] Ошибка при незавершённом многострочном комментарии

## Ошибки и конец файла

- [x] Ошибка при неизвестном символе
- [x] Пустой исходный текст сразу возвращает конец файла
- [x] Текст только из пробельных символов сразу возвращает конец файла
- [x] Текст только из комментариев сразу возвращает конец файла
- [x] После последней лексемы возвращается токен конца файла

## Загрузка исходного файла

- [x] Загрузка и разбор многострочного `.lait`-файла целиком
- [x] Построение пути к тестовому файлу без зависимости от операционной системы
- [x] Стандартная ошибка при попытке загрузить отсутствующий файл
