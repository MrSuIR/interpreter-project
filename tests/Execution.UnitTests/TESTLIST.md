# Проверки модуля выполнения

## Встроенные функции

- Определены только функции из спецификации: `print`, `readInt`, `abs`, `min`, `max`.
- Имена параметров и наличие результата соответствуют таблице встроенных функций.
- Результаты `abs`, `min`, `max`, включая границы `int`; переполнение `abs`.
- `print` выводит число в десятичной записи и завершает строку.
- `readInt` читает одну строку за вызов; сообщения об ошибках ввода.

## Вычисление AST

- Литералы, все бинарные операции, унарный минус и вложенные вызовы встроенных функций.
- Левая и правая вложенность бинарных операций; деление с усечением к нулю; граница `int`.
- Переполнение каждой операции и `abs`, деление на ноль.
- Операнды и аргументы вычисляются слева направо по одному разу.
- Инструкции выполняются по порядку, результаты выражений отбрасываются.
- Ошибка выполнения прекращает дальнейшие инструкции и сохраняет вывод.
- Вызов функции без результата не имеет значения.
- Нехватка стека при глубокой вложенности даёт обработанную ошибку.
