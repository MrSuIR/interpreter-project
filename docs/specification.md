# Спецификация языка Lait

## Введение

Lait - строго типизированный императивный язык программирования, предназначенный для учебной разработки интерпретатора.

Исходный код программы на Lait хранится в одном файле с расширением `.lait`. Точкой входа является функция `main`. Во второй итерации реализуется подмножество языка: последовательное выполнение инструкций, целочисленная арифметика и вызовы встроенных функций. Ветвления, циклы, пользовательские функции, явно объявляемые переменные, одномерные массивы и пользовательские структуры планируются для следующих итераций.

Lait использует строгую типизацию. Во второй итерации поддерживается только тип `int` для целых чисел. Типы `string` для строк и `bool` для булевых значений предусмотрены для следующих итераций. Обозначение `void` указывает отсутствие возвращаемого значения.

Язык поддерживает процедурный стиль программирования. Планируемые пользовательские структуры предназначены для объединения связанных данных и не содержат методов. Во второй итерации ввод и вывод чисел выполняются с помощью встроенных функций `readInt` и `print`; функция `readString` предусмотрена для следующих итераций.

По внешнему виду Lait близок к C и C#: блоки обозначаются фигурными скобками, инструкции завершаются точкой с запятой. Во второй итерации используются арифметические операторы; логические операторы и операторы сравнения предусмотрены для следующих итераций. В отличие от C# язык не поддерживает классы, наследование и исключения, что уменьшает объём реализации.

## Лексика

Лексер распознаёт токены текущей и будущих итераций. Допустимые конструкции второй итерации определены в разделе синтаксиса.

Если одна последовательность символов может начинать несколько лексем, выбирается самая длинная подходящая лексема. Например, последовательность `>=` распознаётся как один оператор, а не как два оператора `>` и `=`.

### Ключевые слова

Ключевые слова чувствительны к регистру и не могут использоваться как идентификаторы. Например, `string` является ключевым словом, а `String` - идентификатором.

| Ключевое слово | Назначение |
| --- | --- |
| `bool` | Обозначает булев тип |
| `else` | Начинает альтернативную ветвь условной инструкции |
| `false` | Обозначает ложное булево значение |
| `func` | Начинает объявление функции |
| `if` | Начинает условную инструкцию |
| `int` | Обозначает целочисленный тип |
| `new` | Используется при создании массива или структуры |
| `return` | Завершает выполнение функции и возвращает результат |
| `string` | Обозначает строковый тип |
| `struct` | Начинает объявление структуры |
| `true` | Обозначает истинное булево значение |
| `void` | Обозначает отсутствие возвращаемого значения |
| `while` | Начинает цикл с условием |

Имена `main`, `print`, `readInt`, `readString`, `abs`, `min` и `max` не являются ключевыми словами и распознаются как идентификаторы.

### Идентификаторы

Идентификатор - это имя переменной, функции, параметра, структуры или поля структуры.

Идентификатор состоит из английских букв (`a`-`z`, `A`-`Z`), десятичных цифр (`0`-`9`) и символов подчёркивания (`_`) и должен начинаться с английской буквы. Регистр имеет значение: `value`, `Value` и `VALUE` являются разными идентификаторами.

Примеры допустимых идентификаторов: `x`, `userName`, `Point2D`, `read_value`.

Примеры недопустимых идентификаторов: `2value`, `_value`, `имя`.

### Литералы

#### Целочисленные литералы

Целочисленный литерал записывается в десятичной системе счисления и состоит из одной или нескольких цифр. Литерал `0` записывается одной цифрой; остальные литералы не могут начинаться с нуля.

Знак не является частью литерала. Например, в записи `-15` символ `-` является отдельным оператором, а `15` - целочисленным литералом.

Допустимый диапазон целочисленных литералов - от `0` до `2147483647` включительно.

#### Строковые литералы

Строковый литерал состоит из нуля или более символов и заключается в двойные кавычки. Строка может содержать символы Unicode, кроме непечатных управляющих символов. Двойная кавычка, обратная косая черта и управляющие символы записываются с помощью escape-последовательностей.

| Последовательность | Значение |
| --- | --- |
| `\n` | Перенос строки |
| `\t` | Горизонтальная табуляция |
| `\"` | Двойная кавычка |
| `\\` | Обратная косая черта |

Обычный перенос строки внутри строкового литерала не допускается. Примеры допустимых строковых литералов: `""`, `"Lait"`, `"First line\nSecond line"`.

#### Булевы литералы

В языке есть два булевых литерала: `true` и `false`. Они одновременно являются ключевыми словами и чувствительны к регистру.

### Операторы

| Оператор | Назначение |
| --- | --- |
| `+` | Сложение чисел |
| `-` | Вычитание или унарный минус |
| `*` | Умножение |
| `/` | Деление |
| `=` | Присваивание |
| `==` | Сравнение "равно" |
| `!=` | Сравнение "не равно" |
| `<` | Сравнение "меньше" |
| `<=` | Сравнение "меньше или равно" |
| `>` | Сравнение "больше" |
| `>=` | Сравнение "больше или равно" |
| `&&` | Логическое "и" |
| `\|\|` | Логическое "или" |
| `!` | Логическое отрицание |
| `.` | Доступ к полю структуры |

### Скобки и разделители

| Лексема | Назначение |
| --- | --- |
| `(` | Открывающая круглая скобка |
| `)` | Закрывающая круглая скобка |
| `{` | Открывающая фигурная скобка |
| `}` | Закрывающая фигурная скобка |
| `[` | Открывающая квадратная скобка |
| `]` | Закрывающая квадратная скобка |
| `,` | Разделение параметров, аргументов, элементов и полей |
| `:` | Отделение имени от типа |
| `;` | Завершение инструкции |

### Пробельные символы

Между токенами игнорируются следующие пробельные символы:

| Символ | Обозначение |
| --- | --- |
| Пробел | `" "` |
| Горизонтальная табуляция | `\t` |
| Перенос строки | `\n` |
| Возврат каретки | `\r` |

Пробельные символы обязательны только там, где без них соседние последовательности были бы распознаны как одна лексема. Например, в записи `int value` пробел отделяет ключевое слово `int` от идентификатора `value`.

### Комментарии

Однострочный комментарий начинается с `//` и продолжается до переноса строки или конца файла.

Многострочный комментарий начинается с `/*` и заканчивается ближайшей последовательностью `*/`. Он может содержать переносы строк. Вложенные многострочные комментарии не поддерживаются.

Последовательности, похожие на начало или конец комментария, внутри строкового литерала являются частью строки.

### Лексические ошибки

Лексической ошибкой считается:

- символ, который не входит ни в одну допустимую лексему;
- целочисленный литерал с запрещённым ведущим нулём;
- целочисленный литерал вне допустимого диапазона;
- незавершённый строковый литерал;
- обычный перенос строки или непечатный управляющий символ внутри строкового литерала;
- неизвестная escape-последовательность;
- незавершённый многострочный комментарий.

## Синтаксис второй итерации

### Программа и инструкции

Программа содержит ровно одну функцию `func main(): void` без параметров. Её тело заключается в фигурные скобки и содержит последовательность инструкций. Тело может быть пустым. Инструкции выполняются по порядку.

Инструкцией может быть числовое выражение или вызов `print`. Каждая инструкция завершается точкой с запятой. Результат самостоятельного выражения отбрасывается, но входящие в него вызовы функций выполняются.

Числовое выражение состоит из целочисленных литералов, арифметических операций, круглых скобок и вызовов `readInt`, `abs`, `min`, `max`. Вызов `print` не возвращает значения и допускается только как отдельная инструкция.

Во второй итерации поддерживается только тип `int`. Переменные и пользовательские функции не поддерживаются.

### Операторы: приоритет и ассоциативность

Операторы с большим номером приоритета выполняются раньше операторов с меньшим номером.

| Приоритет | Оператор | Назначение | Ассоциативность |
| --- | --- | --- | --- |
| 3 | `-` (унарный) | Смена знака числа | Правая |
| 2 | `*`, `/` | Умножение и целочисленное деление | Левая |
| 1 | `+`, `-` (бинарный) | Сложение и вычитание | Левая |

Круглые скобки позволяют изменить порядок операций. Вызов числовой функции можно использовать как операнд. Унарный плюс не поддерживается.

### Правила вычислений

Значения типа `int` лежат в диапазоне от `-2147483648` до `2147483647` включительно. Диапазон целочисленных литералов указан в разделе лексики.

Деление целочисленное, дробная часть отбрасывается в сторону нуля: `7 / 2` даёт `3`, а `-7 / 2` даёт `-3`. Деление на ноль и выход результата любой операции за диапазон `int` являются ошибками выполнения.

Операнды бинарных операций и аргументы функций вычисляются слева направо. Каждый аргумент вычисляется один раз. При ошибке выполнение программы прекращается.

### Встроенные функции

| Функция | Результат и действие |
| --- | --- |
| `print(value: int): void` | Выводит число в десятичной записи и завершает строку |
| `readInt(): int` | Читает одну строку стандартного ввода и возвращает целое число |
| `abs(value: int): int` | Возвращает модуль числа |
| `min(left: int, right: int): int` | Возвращает меньшее из двух чисел |
| `max(left: int, right: int): int` | Возвращает большее из двух чисел |

Все аргументы должны быть числовыми выражениями.

`readInt` читает число без приглашения ко вводу. В строке допускаются начальные и конечные пробелы и табуляции, необязательный знак `+` или `-` и десятичные цифры от `0` до `9`. Ведущие нули допускаются. Пустая строка, неверная запись числа, конец ввода до получения строки и число вне диапазона `int` являются ошибками выполнения.

### Грамматика ISO EBNF

Грамматика описывает поток токенов лексера. Специальная последовательность ISO EBNF `? IntLiteral ?` обозначает токен целочисленного литерала. Остальные терминалы записаны в кавычках.

Терминалы `"main"`, `"print"`, `"readInt"`, `"abs"`, `"min"`, `"max"` обозначают идентификаторы с указанными именами. Начальное правило `program` описывает весь файл.

```ebnf
(* Точка входа и её тело *)
program = "func", "main", "(", ")", ":", "void", block ;
block = "{", { statement }, "}" ;

(* Инструкции *)
statement = ( print_call | expression ), ";" ;
print_call = "print", "(", expression, ")" ;

(* Арифметика: от меньшего приоритета к большему *)
expression = additive_expression ;
additive_expression = multiplicative_expression,
    { ( "+" | "-" ), multiplicative_expression } ;
multiplicative_expression = unary_expression,
    { ( "*" | "/" ), unary_expression } ;
unary_expression = "-", unary_expression | primary_expression ;

(* Число, группировка или вызов числовой функции *)
primary_expression = ? IntLiteral ?
    | "(", expression, ")"
    | numeric_call ;

(* Вызов числовой функции *)
numeric_call = numeric_function, "(", [ arguments ], ")" ;
numeric_function = "readInt" | "abs" | "min" | "max" ;
arguments = expression, { ",", expression } ;
```

Число аргументов вызова должно соответствовать таблице встроенных функций.
