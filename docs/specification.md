# Спецификация языка Lait

## Введение

Lait - строго типизированный императивный язык программирования, предназначенный для учебной разработки интерпретатора.

Исходный код программы на Lait хранится в одном файле с расширением `.lait`. Точкой входа является функция `main`. В текущей итерации программа состоит из последовательности числовых выражений и операций ввода/вывода.

Единственный тип значений текущей итерации — `int` для целых чисел. Обозначение `void` в заголовке `main` означает отсутствие возвращаемого значения и не является типом значений выражений.

Ввод выполняется с помощью встроенной функции `readInt()`, вывод — инструкцией `print(expression);`. Также доступны встроенные функции `abs`, `min` и `max`. Ввод чисел и набор из трёх встроенных вычислительных функций являются двумя особенностями языка в этой итерации.

По внешнему виду Lait близок к C и C#: блоки обозначаются фигурными скобками, инструкции завершаются точкой с запятой, выражения используют арифметические операторы.

### Возможности следующих этапов

Ветвления, циклы, пользовательские функции, явно объявляемые переменные, одномерные массивы, пользовательские структуры, типы `string` и `bool`, логические операции, сравнения и ввод строк через `readString` планируются для следующих этапов. Пользовательские структуры предназначены для объединения связанных данных и не содержат методов. Классы, наследование и исключения не планируются.

Раздел «Лексика» сохраняет набор лексем для следующих этапов, уже распознаваемых лексером. Наличие лексемы в этом разделе не означает, что она допустима в программе текущей итерации: допустимый синтаксис задаётся разделом «Грамматика».

## Лексика

Если одна последовательность символов может начинать несколько лексем, выбирается самая длинная подходящая лексема. Например, последовательность `>=` распознаётся как один оператор, а не как два оператора `>` и `=`.

### Ключевые слова

Ключевые слова чувствительны к регистру и не могут использоваться как идентификаторы. Например, `string` является ключевым словом, а `String` - идентификатором.

| Ключевое слово | Назначение |
| --- | --- |
| `bool` | Обозначает булев тип |
| `else` | Начинает альтернативную ветвь условной инструкции |
| `false` | Обозначает ложное булево значение |
| `func` | Начинает объявление функции |
| `if` | Начинает условную инструкцию |
| `int` | Обозначает целочисленный тип |
| `new` | Используется при создании массива или структуры |
| `return` | Завершает выполнение функции и возвращает результат |
| `string` | Обозначает строковый тип |
| `struct` | Начинает объявление структуры |
| `true` | Обозначает истинное булево значение |
| `void` | Обозначает отсутствие возвращаемого значения |
| `while` | Начинает цикл с условием |

Имена `main`, `print`, `readInt`, `abs`, `min`, `max` и `readString` не являются ключевыми словами и распознаются как идентификаторы.

### Идентификаторы

Идентификатор — это имя. В текущей итерации допустимы только имена, явно указанные в грамматике; имена переменных, пользовательских функций, параметров, структур и полей структур предназначены для следующих этапов.

Идентификатор состоит из английских букв (`a`-`z`, `A`-`Z`), десятичных цифр (`0`-`9`) и символов подчёркивания (`_`) и должен начинаться с английской буквы. Регистр имеет значение: `value`, `Value` и `VALUE` являются разными идентификаторами.

Примеры допустимых идентификаторов: `x`, `userName`, `Point2D`, `read_value`.

Примеры недопустимых идентификаторов: `2value`, `_value`, `имя`.

### Литералы

#### Целочисленные литералы

Целочисленный литерал записывается в десятичной системе счисления и состоит из одной или нескольких цифр. Литерал `0` записывается одной цифрой; остальные литералы не могут начинаться с нуля.

Знак не является частью литерала. Например, в записи `-15` символ `-` является отдельным оператором, а `15` - целочисленным литералом.

Допустимый диапазон целочисленных литералов - от `0` до `2147483647` включительно.

#### Строковые литералы

Строковый литерал состоит из нуля или более символов и заключается в двойные кавычки. Строка может содержать символы Unicode, кроме непечатных управляющих символов. Двойная кавычка, обратная косая черта и управляющие символы записываются с помощью escape-последовательностей.

| Последовательность | Значение |
| --- | --- |
| `\n` | Перенос строки |
| `\t` | Горизонтальная табуляция |
| `\"` | Двойная кавычка |
| `\\` | Обратная косая черта |

Обычный перенос строки внутри строкового литерала не допускается. Примеры допустимых строковых литералов: `""`, `"Lait"`, `"First line\nSecond line"`.

#### Булевы литералы

Для следующих этапов предусмотрены два булевых литерала: `true` и `false`. Они одновременно являются ключевыми словами и чувствительны к регистру.

### Операторы

| Оператор | Назначение |
| --- | --- |
| `+` | Сложение чисел |
| `-` | Вычитание или унарный минус |
| `*` | Умножение |
| `/` | Деление |
| `=` | Присваивание |
| `==` | Сравнение "равно" |
| `!=` | Сравнение "не равно" |
| `<` | Сравнение "меньше" |
| `<=` | Сравнение "меньше или равно" |
| `>` | Сравнение "больше" |
| `>=` | Сравнение "больше или равно" |
| `&&` | Логическое "и" |
| `\|\|` | Логическое "или" |
| `!` | Логическое отрицание |
| `.` | Доступ к полю структуры |

### Скобки и разделители

| Лексема | Назначение |
| --- | --- |
| `(` | Открывающая круглая скобка |
| `)` | Закрывающая круглая скобка |
| `{` | Открывающая фигурная скобка |
| `}` | Закрывающая фигурная скобка |
| `[` | Открывающая квадратная скобка |
| `]` | Закрывающая квадратная скобка |
| `,` | Разделение параметров, аргументов, элементов и полей |
| `:` | Отделение имени от типа |
| `;` | Завершение инструкции |

### Пробельные символы

Между токенами игнорируются следующие пробельные символы:

| Символ | Обозначение |
| --- | --- |
| Пробел | `" "` |
| Горизонтальная табуляция | `\t` |
| Перенос строки | `\n` |
| Возврат каретки | `\r` |

Пробельные символы обязательны только там, где без них соседние последовательности были бы распознаны как одна лексема. Например, в записи `int value` пробел отделяет ключевое слово `int` от идентификатора `value`.

### Комментарии

Однострочный комментарий начинается с `//` и продолжается до переноса строки или конца файла.

Многострочный комментарий начинается с `/*` и заканчивается ближайшей последовательностью `*/`. Он может содержать переносы строк. Вложенные многострочные комментарии не поддерживаются.

Последовательности, похожие на начало или конец комментария, внутри строкового литерала являются частью строки.

### Лексические ошибки

Лексической ошибкой считается:

- символ, который не входит ни в одну допустимую лексему;
- целочисленный литерал с запрещённым ведущим нулём;
- целочисленный литерал вне допустимого диапазона;
- незавершённый строковый литерал;
- обычный перенос строки или непечатный управляющий символ внутри строкового литерала;
- неизвестная escape-последовательность;
- незавершённый многострочный комментарий.

## Грамматика

Грамматика текущей итерации записана в диалекте ISO EBNF: `,` обозначает последовательность, `|` — выбор, `{ ... }` — повторение ноль или более раз, `( ... )` — группировку. Правила завершаются `;`.

Записи в кавычках обозначают лексемы с указанным текстом. Имена `main`, `print`, `readInt`, `abs`, `min` и `max` проверяются по тексту токена-идентификатора. Специальная последовательность `? IntLiteral из раздела «Лексика» ?` обозначает терминал целочисленного литерала. Правила формирования терминалов описаны в разделе «Лексика» и здесь не повторяются.

```ebnf
program = "func", "main", "(", ")", ":", "void",
          "{", { statement }, "}" ;

statement = ( printStatement | expression ), ";" ;

printStatement = "print", "(", expression, ")" ;

expression = additiveExpression ;

additiveExpression = multiplicativeExpression,
                     { ( "+" | "-" ), multiplicativeExpression } ;

multiplicativeExpression = unaryExpression,
                           { ( "*" | "/" ), unaryExpression } ;

unaryExpression = "-", unaryExpression | primaryExpression ;

primaryExpression = ? IntLiteral из раздела «Лексика» ?
                  | "(", expression, ")"
                  | readExpression
                  | absoluteExpression
                  | extremaExpression ;

readExpression = "readInt", "(", ")" ;

absoluteExpression = "abs", "(", expression, ")" ;

extremaExpression = ( "min" | "max" ), "(",
                    expression, ",", expression, ")" ;
```

Начальный нетерминал — `program`. После закрывающей скобки `main` требуется конец файла; пробельные символы и комментарии игнорируются лексером. Другие объявления и инструкции вне `main` запрещены. Тело `main` может быть пустым. Каждая инструкция завершается точкой с запятой; отдельная пустая инструкция `;` не допускается.

Грамматика не содержит левой рекурсии. Общие префиксы вынесены, а бинарные операции представлены повторениями, которые при разборе сворачиваются слева. Выбор между именами встроенных функций выполняется по тексту идентификатора.

## Приоритет и ассоциативность операторов

Чем больше число в столбце «Приоритет», тем выше приоритет оператора.

| Приоритет | Операторы | Ассоциативность |
| --- | --- | --- |
| 3 | Унарный `-` | Правая |
| 2 | `*`, `/` | Левая |
| 1 | Бинарные `+`, `-` | Левая |

Круглые скобки изменяют группировку выражения. Встроенные вызовы являются первичными выражениями. Например, `10 - 3 - 2` группируется как `(10 - 3) - 2`, а `--5` — как `-(-5)`. Унарный плюс не поддерживается. Остальные операторы из раздела «Лексика» относятся к следующим этапам.

## Выполнение программы

### Числа и арифметика

Тип `int` представляет знаковые 32-битные целые числа в диапазоне от `-2147483648` до `2147483647`. Диапазон положительных литералов остаётся указанным в разделе «Лексика»: запись `-2147483648` недопустима из-за диапазона литерала, но это значение можно получить как `-2147483647 - 1` или прочитать через `readInt()`.

Операторы `+`, `-`, `*` выполняют сложение, вычитание и умножение. Унарный `-` меняет знак числа. Оператор `/` выполняет целочисленное деление с отбрасыванием дробной части в направлении нуля: `-7 / 2` равно `-3`.

Деление на ноль и выход результата за диапазон `int` являются ошибками выполнения. Переполнение проверяется при каждой операции; это относится и к отрицанию минимального значения `int`, и к его делению на `-1`.

### Встроенные функции и вывод

| Вызов | Результат или действие |
| --- | --- |
| `readInt(): int` | Читает одну строку стандартного ввода и возвращает целое число |
| `abs(x: int): int` | Возвращает модуль `x` |
| `min(x: int, y: int): int` | Возвращает меньшее из двух чисел |
| `max(x: int, y: int): int` | Возвращает большее из двух чисел |
| `print(expression);` | Выводит значение выражения в стандартный вывод и добавляет перевод строки |

Сигнатуры в таблице описывают функции, а не синтаксис их объявления. Вызовы допускают ровно указанное число аргументов; аргументы могут быть произвольными числовыми выражениями, включая вложенные вызовы. `print` является инструкцией и не может использоваться внутри выражения.

Ввод для `readInt()` содержит десятичные цифры `0`–`9` с необязательным знаком `+` или `-` непосредственно перед ними. По краям строки допускаются пробелы и горизонтальная табуляция. Ведущие нули во вводе разрешены: ограничения литералов исходного кода на ввод не распространяются. Пустая строка, неверный формат, значение вне диапазона `int` и конец ввода являются ошибками выполнения. Модуль минимального значения `int` также вызывает ошибку переполнения.

`print` выводит десятичную запись числа без ведущих нулей, с минусом для отрицательного значения, без дополнительных пробелов.

### Порядок выполнения и ошибки

Инструкции выполняются последовательно. Операнды бинарных операций и аргументы функций вычисляются слева направо. Результат самостоятельного выражения отбрасывается; вызовы `readInt()` в нём по-прежнему читают ввод. Функция `main` завершается после последней инструкции и не возвращает значение.

Нарушение грамматики, в том числе неизвестное имя, неверное число аргументов или отсутствие `;`, является синтаксической ошибкой. Программа с лексической или синтаксической ошибкой не выполняется. При ошибке выполнения интерпретатор сообщает о ней и прекращает выполнение; уже выполненные ввод и вывод сохраняются. Точный текст диагностик не регламентируется.

## Примеры

### Ввод и встроенные функции

```lait
func main(): void {
    print(abs(readInt()));
    print(min(8, 3));
    print(max(2, min(9, 5)));
}
```

Если на вход подана строка `-7`, программа выводит:

```text
7
3
5
```

### Приоритет и ассоциативность

```lait
func main(): void {
    1 + 2; // Результат выражения отбрасывается.
    print(2 + 3 * 4);
    print((2 + 3) * 4);
    print(10 - 3 - 2);
    print(--5);
    print(-7 / 2);
}
```

Результат:

```text
14
20
5
5
-3
```
