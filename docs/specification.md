# Спецификация языка Lait

## Введение

Lait - строго типизированный императивный язык программирования, предназначенный для учебной разработки интерпретатора.

Исходный код программы на Lait хранится в одном файле с расширением `.lait`. Точкой входа является функция `main`. В третьей итерации реализуется подмножество языка: целочисленная арифметика, явно объявляемые переменные, присваивание, вложенные блоки, пользовательские и встроенные функции. Ветвления, циклы, одномерные массивы и пользовательские структуры планируются для следующих итераций.

Lait использует строгую типизацию. В третьей итерации поддерживается только тип `int` для целых чисел. Типы `string` для строк и `bool` для булевых значений предусмотрены для следующих итераций. Обозначение `void` указывает отсутствие возвращаемого значения.

Язык поддерживает процедурный стиль программирования. Планируемые пользовательские структуры предназначены для объединения связанных данных и не содержат методов. В третьей итерации ввод и вывод чисел выполняются с помощью встроенных функций `readInt` и `print`; функция `readString` предусмотрена для следующих итераций.

По внешнему виду Lait близок к C и C#: блоки обозначаются фигурными скобками, инструкции завершаются точкой с запятой. В третьей итерации используются арифметические операторы и присваивание; логические операторы и операторы сравнения предусмотрены для следующих итераций. В отличие от C# язык не поддерживает классы, наследование и исключения, что уменьшает объём реализации.

## Лексика

Лексер распознаёт токены текущей и будущих итераций. Допустимые конструкции третьей итерации определены в разделе синтаксиса.

Если одна последовательность символов может начинать несколько лексем, выбирается самая длинная подходящая лексема. Например, последовательность `>=` распознаётся как один оператор, а не как два оператора `>` и `=`.

### Ключевые слова

Ключевые слова чувствительны к регистру и не могут использоваться как идентификаторы. Например, `string` является ключевым словом, а `String` - идентификатором.

| Ключевое слово | Назначение |
| --- | --- |
| `bool` | Обозначает булев тип |
| `else` | Начинает альтернативную ветвь условной инструкции |
| `false` | Обозначает ложное булево значение |
| `func` | Начинает объявление функции |
| `if` | Начинает условную инструкцию |
| `int` | Обозначает целочисленный тип |
| `new` | Используется при создании массива или структуры |
| `return` | Завершает выполнение функции и возвращает результат |
| `string` | Обозначает строковый тип |
| `struct` | Начинает объявление структуры |
| `true` | Обозначает истинное булево значение |
| `void` | Обозначает отсутствие возвращаемого значения |
| `while` | Начинает цикл с условием |

Имена `main`, `print`, `readInt`, `readString`, `abs`, `min` и `max` не являются ключевыми словами и распознаются как идентификаторы.

### Идентификаторы

Идентификатор - это имя переменной, функции, параметра, структуры или поля структуры.

Идентификатор состоит из английских букв (`a`-`z`, `A`-`Z`), десятичных цифр (`0`-`9`) и символов подчёркивания (`_`) и должен начинаться с английской буквы. Регистр имеет значение: `value`, `Value` и `VALUE` являются разными идентификаторами.

Примеры допустимых идентификаторов: `x`, `userName`, `Point2D`, `read_value`.

Примеры недопустимых идентификаторов: `2value`, `_value`, `имя`.

### Литералы

#### Целочисленные литералы

Целочисленный литерал записывается в десятичной системе счисления и состоит из одной или нескольких цифр. Литерал `0` записывается одной цифрой; остальные литералы не могут начинаться с нуля.

Знак не является частью литерала. Например, в записи `-15` символ `-` является отдельным оператором, а `15` - целочисленным литералом.

Допустимый диапазон целочисленных литералов - от `0` до `2147483647` включительно.

#### Строковые литералы

Строковый литерал состоит из нуля или более символов и заключается в двойные кавычки. Строка может содержать символы Unicode, кроме непечатных управляющих символов. Двойная кавычка, обратная косая черта и управляющие символы записываются с помощью escape-последовательностей.

| Последовательность | Значение |
| --- | --- |
| `\n` | Перенос строки |
| `\t` | Горизонтальная табуляция |
| `\"` | Двойная кавычка |
| `\\` | Обратная косая черта |

Обычный перенос строки внутри строкового литерала не допускается. Примеры допустимых строковых литералов: `""`, `"Lait"`, `"First line\nSecond line"`.

#### Булевы литералы

В языке есть два булевых литерала: `true` и `false`. Они одновременно являются ключевыми словами и чувствительны к регистру.

### Операторы

| Оператор | Назначение |
| --- | --- |
| `+` | Сложение чисел |
| `-` | Вычитание или унарный минус |
| `*` | Умножение |
| `/` | Деление |
| `=` | Присваивание |
| `==` | Сравнение "равно" |
| `!=` | Сравнение "не равно" |
| `<` | Сравнение "меньше" |
| `<=` | Сравнение "меньше или равно" |
| `>` | Сравнение "больше" |
| `>=` | Сравнение "больше или равно" |
| `&&` | Логическое "и" |
| `\|\|` | Логическое "или" |
| `!` | Логическое отрицание |
| `.` | Доступ к полю структуры |

### Скобки и разделители

| Лексема | Назначение |
| --- | --- |
| `(` | Открывающая круглая скобка |
| `)` | Закрывающая круглая скобка |
| `{` | Открывающая фигурная скобка |
| `}` | Закрывающая фигурная скобка |
| `[` | Открывающая квадратная скобка |
| `]` | Закрывающая квадратная скобка |
| `,` | Разделение параметров, аргументов, элементов и полей |
| `:` | Отделение имени от типа |
| `;` | Завершение инструкции |

### Пробельные символы

Между токенами игнорируются следующие пробельные символы:

| Символ | Обозначение |
| --- | --- |
| Пробел | `" "` |
| Горизонтальная табуляция | `\t` |
| Перенос строки | `\n` |
| Возврат каретки | `\r` |

Пробельные символы обязательны только там, где без них соседние последовательности были бы распознаны как одна лексема. Например, в записи `int value` пробел отделяет ключевое слово `int` от идентификатора `value`.

### Комментарии

Однострочный комментарий начинается с `//` и продолжается до переноса строки или конца файла.

Многострочный комментарий начинается с `/*` и заканчивается ближайшей последовательностью `*/`. Он может содержать переносы строк. Вложенные многострочные комментарии не поддерживаются.

Последовательности, похожие на начало или конец комментария, внутри строкового литерала являются частью строки.

### Лексические ошибки

Лексической ошибкой считается:

- символ, который не входит ни в одну допустимую лексему;
- целочисленный литерал с запрещённым ведущим нулём;
- целочисленный литерал вне допустимого диапазона;
- незавершённый строковый литерал;
- обычный перенос строки или непечатный управляющий символ внутри строкового литерала;
- неизвестная escape-последовательность;
- незавершённый многострочный комментарий.

## Синтаксис третьей итерации

### Программа и функции

Программа состоит из одного или нескольких объявлений функций. Объявление задаёт имя функции, параметры, результат и тело-блок: `func sum(left: int, right: int): int { ... }`. Каждый параметр имеет тип `int`. Результат функции имеет тип `int` или `void`.

Программа должна содержать ровно одну функцию `main` без параметров с результатом `void`. Выполнение программы - это вызов `main`. Вызывать `main` из программы нельзя.

Программа выполняется только после разбора всего файла и проверки правил из раздела "Правила проверки". Если найдена лексическая ошибка, ошибка разбора или ошибка проверки, ни одна инструкция не выполняется.

### Инструкции

Тело функции и вложенный блок заключаются в фигурные скобки и содержат последовательность инструкций. Блок может быть пустым. Инструкции выполняются по порядку.

Инструкцией является:

- объявление переменной `int name = expression;`;
- инструкция возврата `return expression;` или `return;`;
- вложенный блок `{ ... }`;
- выражение, после которого стоит точка с запятой.

Результат выражения в инструкции отбрасывается, но входящие в него присваивания и вызовы функций выполняются.

### Выражения

Выражение состоит из целочисленных литералов, имён переменных, арифметических операций, присваиваний, круглых скобок и вызовов функций. Идентификатор, после которого стоит `(`, обозначает вызов функции, остальные идентификаторы в выражении обозначают переменные.

Присваивание `name = expression` записывает значение правой части в переменную и само имеет это значение. Присваивания можно вкладывать: `a = b = c` означает `a = (b = c)`.

### Операторы: приоритет и ассоциативность

Операторы с большим номером приоритета выполняются раньше операторов с меньшим номером.

| Приоритет | Оператор | Назначение | Ассоциативность |
| --- | --- | --- | --- |
| 4 | `-` (унарный) | Смена знака числа | Правая |
| 3 | `*`, `/` | Умножение и целочисленное деление | Левая |
| 2 | `+`, `-` (бинарный) | Сложение и вычитание | Левая |
| 1 | `=` | Присваивание | Правая |

Круглые скобки позволяют изменить порядок операций. Вызов функции с результатом `int` можно использовать как операнд. Унарный плюс не поддерживается.

### Области видимости

Области видимости лексические. Тело функции и каждый вложенный блок образуют область видимости. Параметры функции принадлежат области её тела.

Переменная видна от конца своего объявления до конца блока, в котором она объявлена, включая вложенные блоки. Инициализатор вычисляется до создания переменной и не видит объявляемую переменную. Инициализация обязательна, поэтому неинициализированных переменных нет.

В одной области видимости имена переменных и параметров не повторяются. Во вложенном блоке можно объявить переменную с именем внешней переменной или параметра; до конца блока новая переменная перекрывает внешнюю.

Функции объявляются только на верхнем уровне программы и видны во всей программе независимо от порядка объявления. Функция может вызывать себя и другие функции. Тело функции видит только свои параметры и переменные, но не переменные других функций.

Имена функций и имена переменных находятся в разных пространствах имён, поэтому переменная может называться так же, как функция.

### Правила проверки

Нарушение любого из правил является ошибкой проверки:

- в программе ровно одна функция `main`; у неё нет параметров, её результат `void`, и её нельзя вызывать;
- имена пользовательских функций не повторяются и не совпадают с именами встроенных функций;
- имена параметров одной функции не повторяются;
- каждая используемая переменная объявлена и видна в месте использования;
- вызываемая функция объявлена в программе или является встроенной, а число аргументов совпадает с числом её параметров;
- вызов функции с результатом `void` является всем выражением инструкции; скобки вокруг такого вызова допустимы;
- левый операнд присваивания является именем переменной, возможно в круглых скобках;
- `return` с выражением допускается только в функции с результатом `int`, а `return` без выражения - только в функции с результатом `void`;
- последняя инструкция тела функции с результатом `int` является `return` с выражением.

### Правила вычислений

Значения типа `int` лежат в диапазоне от `-2147483648` до `2147483647` включительно. Диапазон целочисленных литералов указан в разделе лексики.

Деление целочисленное, дробная часть отбрасывается в сторону нуля: `7 / 2` даёт `3`, а `-7 / 2` даёт `-3`. Деление на ноль и выход результата любой операции за диапазон `int` являются ошибками выполнения.

Операнды бинарных операций и аргументы функций вычисляются слева направо. Каждый аргумент вычисляется один раз. В присваивании сначала вычисляется правая часть.

При вызове пользовательской функции её параметры получают значения аргументов. Параметры передаются по значению: присваивание параметра не изменяет переменные вызывающей функции. Тело выполняется в новой области видимости. `return` с выражением завершает функцию и возвращает значение выражения. Функция с результатом `void` завершается инструкцией `return;` или после последней инструкции тела.

Ошибка выполнения прекращает программу; уже выполненные ввод и вывод сохраняются. Нехватка стека при разборе, проверке или выполнении глубоко вложенных выражений и вызовов является ошибкой.

### Встроенные функции

| Функция | Результат и действие |
| --- | --- |
| `print(value: int): void` | Выводит число в десятичной записи и завершает строку |
| `readInt(): int` | Читает одну строку стандартного ввода и возвращает целое число |
| `abs(value: int): int` | Возвращает модуль числа |
| `min(left: int, right: int): int` | Возвращает меньшее из двух чисел |
| `max(left: int, right: int): int` | Возвращает большее из двух чисел |

`readInt` читает число без приглашения ко вводу. В строке допускаются начальные и конечные пробелы и табуляции, необязательный знак `+` или `-` и десятичные цифры от `0` до `9`. Ведущие нули допускаются. Пустая строка, неверная запись числа, конец ввода до получения строки и число вне диапазона `int` являются ошибками выполнения.

### Грамматика ISO EBNF

Грамматика описывает поток токенов лексера. Специальные последовательности ISO EBNF `? IntLiteral ?` и `? Identifier ?` обозначают токены целочисленного литерала и идентификатора. Остальные терминалы записаны в кавычках. Начальное правило `program` описывает весь файл.

```ebnf
(* Программа и функции *)
program = function_declaration, { function_declaration } ;
function_declaration = "func", ? Identifier ?, "(", [ parameters ], ")", ":", result_type, block ;
parameters = parameter, { ",", parameter } ;
parameter = ? Identifier ?, ":", "int" ;
result_type = "int" | "void" ;

(* Блоки и инструкции *)
block = "{", { statement }, "}" ;
statement = variable_declaration
    | return_statement
    | block
    | expression_statement ;
variable_declaration = "int", ? Identifier ?, "=", expression, ";" ;
return_statement = "return", [ expression ], ";" ;
expression_statement = expression, ";" ;

(* Выражения: от меньшего приоритета к большему *)
expression = assignment_expression ;
assignment_expression = additive_expression, [ "=", assignment_expression ] ;
additive_expression = multiplicative_expression,
    { ( "+" | "-" ), multiplicative_expression } ;
multiplicative_expression = unary_expression,
    { ( "*" | "/" ), unary_expression } ;
unary_expression = "-", unary_expression | primary_expression ;

(* Число, группировка, переменная или вызов функции *)
primary_expression = ? IntLiteral ?
    | "(", expression, ")"
    | ? Identifier ?, [ argument_list ] ;
argument_list = "(", [ expression, { ",", expression } ], ")" ;
```

Грамматика не содержит левой рекурсии: повторяющиеся операции с левой ассоциативностью записаны повторением `{ }`, а правоассоциативное присваивание - правой рекурсией. Общий префикс альтернатив вынесен: имя переменной и вызов функции начинаются с `? Identifier ?` и различаются необязательным `argument_list`. Поэтому альтернативы каждого правила различаются по первой лексеме: `statement` - по `int`, `return`, `{` или началу выражения, `primary_expression` - по литералу, `(` или идентификатору. Необязательная часть `assignment_expression` начинается с `=`, который не может следовать за выражением иначе.
