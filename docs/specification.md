# Спецификация языка Lait

## Введение

Lait - строго типизированный императивный язык программирования, предназначенный для учебной разработки интерпретатора.

Исходный код программы на Lait хранится в одном файле с расширением `.lait`. Точкой входа является функция `main`. В четвёртой итерации реализуется подмножество языка: типы `int`, `float` и `bool`, арифметические, логические операции и операции сравнения, явно объявляемые переменные, присваивание, вложенные блоки, ветвления, циклы, пользовательские и встроенные функции. Одномерные массивы, строки и пользовательские структуры планируются для следующих итераций.

Lait использует строгую типизацию. В четвёртой итерации поддерживаются тип `int` для целых чисел, тип `float` для чисел с плавающей точкой и тип `bool` для булевых значений. Тип `string` для строк предусмотрен для следующих итераций. Обозначение `void` указывает отсутствие возвращаемого значения.

Язык поддерживает процедурный стиль программирования. Планируемые пользовательские структуры предназначены для объединения связанных данных и не содержат методов. В четвёртой итерации ввод и вывод чисел выполняются с помощью встроенных функций `readInt`, `readFloat`, `print` и `printFloat`; функция `readString` предусмотрена для следующих итераций.

По внешнему виду Lait близок к C и C#: блоки обозначаются фигурными скобками, инструкции завершаются точкой с запятой. В отличие от C# язык не поддерживает классы, наследование и исключения, что уменьшает объём реализации.

## Лексика

Лексер распознаёт токены текущей и будущих итераций. Допустимые конструкции четвёртой итерации определены в разделе синтаксиса.

Если одна последовательность символов может начинать несколько лексем, выбирается самая длинная подходящая лексема. Например, последовательность `>=` распознаётся как один оператор, а не как два оператора `>` и `=`.

### Ключевые слова

Ключевые слова чувствительны к регистру и не могут использоваться как идентификаторы. Например, `string` является ключевым словом, а `String` - идентификатором.

| Ключевое слово | Назначение |
| --- | --- |
| `bool` | Обозначает булев тип |
| `break` | Прерывает цикл |
| `continue` | Переходит к следующему шагу цикла |
| `else` | Начинает альтернативную ветвь условной инструкции |
| `false` | Обозначает ложное булево значение |
| `float` | Обозначает тип чисел с плавающей точкой |
| `for` | Начинает цикл со счётчиком |
| `func` | Начинает объявление функции |
| `if` | Начинает условную инструкцию |
| `int` | Обозначает целочисленный тип |
| `new` | Используется при создании массива или структуры |
| `return` | Завершает выполнение функции и возвращает результат |
| `string` | Обозначает строковый тип |
| `struct` | Начинает объявление структуры |
| `true` | Обозначает истинное булево значение |
| `void` | Обозначает отсутствие возвращаемого значения |
| `while` | Начинает цикл с условием |

Имена `main`, `print`, `printFloat`, `readInt`, `readFloat`, `readString`, `abs`, `min`, `max`, `toFloat` и `toInt` не являются ключевыми словами и распознаются как идентификаторы.

### Идентификаторы

Идентификатор - это имя переменной, функции, параметра, структуры или поля структуры.

Идентификатор состоит из английских букв (`a`-`z`, `A`-`Z`), десятичных цифр (`0`-`9`) и символов подчёркивания (`_`) и должен начинаться с английской буквы. Регистр имеет значение: `value`, `Value` и `VALUE` являются разными идентификаторами.

Примеры допустимых идентификаторов: `x`, `userName`, `Point2D`, `read_value`.

Примеры недопустимых идентификаторов: `2value`, `_value`, `имя`.

### Литералы

#### Целочисленные литералы

Целочисленный литерал записывается в десятичной системе счисления и состоит из одной или нескольких цифр. Литерал `0` записывается одной цифрой; остальные литералы не могут начинаться с нуля.

Знак не является частью литерала. Например, в записи `-15` символ `-` является отдельным оператором, а `15` - целочисленным литералом.

Допустимый диапазон целочисленных литералов - от `0` до `2147483647` включительно.

#### Литералы с плавающей точкой

Литерал с плавающей точкой состоит из целой части, точки и дробной части, например `0.5`, `3.14`, `100.0`. Обе части содержат хотя бы одну десятичную цифру. Целая часть записывается по правилам целочисленного литерала, но не ограничена диапазоном `int`; дробная часть может начинаться с нуля и заканчиваться нулями. Экспоненциальная запись не поддерживается.

Точка, после которой нет цифры, не входит в литерал: `1.` распознаётся как литерал `1` и оператор `.`, а `.5` - как оператор `.` и литерал `5`.

Значение литерала округляется до ближайшего значения типа `float`. Литерал, значение которого не помещается в тип `float`, является ошибкой.

#### Строковые литералы

Строковый литерал состоит из нуля или более символов и заключается в двойные кавычки. Строка может содержать символы Unicode, кроме непечатных управляющих символов. Двойная кавычка, обратная косая черта и управляющие символы записываются с помощью escape-последовательностей.

| Последовательность | Значение |
| --- | --- |
| `\n` | Перенос строки |
| `\t` | Горизонтальная табуляция |
| `\"` | Двойная кавычка |
| `\\` | Обратная косая черта |

Обычный перенос строки внутри строкового литерала не допускается. Примеры допустимых строковых литералов: `""`, `"Lait"`, `"First line\nSecond line"`.

#### Булевы литералы

В языке есть два булевых литерала: `true` и `false`. Они одновременно являются ключевыми словами и чувствительны к регистру.

### Операторы

| Оператор | Назначение |
| --- | --- |
| `+` | Сложение чисел |
| `-` | Вычитание или унарный минус |
| `*` | Умножение |
| `/` | Деление |
| `%` | Остаток от деления |
| `=` | Присваивание |
| `==` | Сравнение "равно" |
| `!=` | Сравнение "не равно" |
| `<` | Сравнение "меньше" |
| `<=` | Сравнение "меньше или равно" |
| `>` | Сравнение "больше" |
| `>=` | Сравнение "больше или равно" |
| `&&` | Логическое "и" |
| `\|\|` | Логическое "или" |
| `!` | Логическое отрицание |
| `.` | Доступ к полю структуры |

### Скобки и разделители

| Лексема | Назначение |
| --- | --- |
| `(` | Открывающая круглая скобка |
| `)` | Закрывающая круглая скобка |
| `{` | Открывающая фигурная скобка |
| `}` | Закрывающая фигурная скобка |
| `[` | Открывающая квадратная скобка |

### Пробельные символы

Между токенами игнорируются следующие пробельные символы:

| Символ | Обозначение |
| --- | --- |
| Пробел | `" "` |
| Горизонтальная табуляция | `\t` |
| Перенос строки | `\n` |
| Возврат каретки | `\r` |

Пробельные символы обязательны только там, где без них соседние последовательности были бы распознаны как одна лексема. Например, в записи `int value` пробел отделяет ключевое слово `int` от идентификатора `value`.

### Комментарии

Однострочный комментарий начинается с `//` и продолжается до переноса строки или конца файла.

Многострочный комментарий начинается с `/*` и заканчивается ближайшей последовательностью `*/`. Он может содержать переносы строк. Вложенные многострочные комментарии не поддерживаются.

Последовательности, похожие на начало или конец комментария, внутри строкового литерала являются частью строки.

### Лексические ошибки

Лексической ошибкой считается:

- символ, который не входит ни в одну допустимую лексему;
- целочисленный литерал или целая часть литерала с плавающей точкой с запрещённым ведущим нулём;
- целочисленный литерал вне допустимого диапазона;
- литерал с плавающей точкой, значение которого не помещается в тип `float`;
- незавершённый строковый литерал;
- обычный перенос строки или непечатный управляющий символ внутри строкового литерала;
- неизвестная escape-последовательность;
- незавершённый многострочный комментарий.

## Синтаксис четвёртой итерации

### Программа и функции

Программа состоит из одного или нескольких объявлений функций. Объявление задаёт имя функции, параметры с типами, тип результата и тело-блок: `func average(sum: int, count: int): float { ... }`. Параметр имеет тип `int`, `float` или `bool`. Результат функции имеет тип `int`, `float`, `bool` или `void`.

Выполнение программы - это вызов функции `main`.

Программа выполняется только после разбора всего файла и проверки правил из раздела "Правила проверки". Если найдена лексическая ошибка, ошибка разбора или ошибка проверки, ни одна инструкция не выполняется.

### Типы

| Тип | Значения |
| --- | --- |
| `int` | Целые числа от `-2147483648` до `2147483647` включительно |
| `float` | Конечные числа двойной точности IEEE 754 (64 бита) |
| `bool` | `true` и `false` |

Неявных преобразований между типами нет. Число типа `int` преобразуется в `float` встроенной функцией `toFloat`, число типа `float` в `int` - функцией `toInt`. Преобразований между `bool` и числами нет.

### Инструкции

Тело функции и вложенный блок заключаются в фигурные скобки и содержат последовательность инструкций. Блок может быть пустым. Инструкции выполняются по порядку.

Инструкцией является:

- объявление переменной `type name = expression;`, где `type` - это `int`, `float` или `bool`;
- условная инструкция `if (condition) { ... }` с необязательной ветвью `else { ... }` или `else if ...`;
- цикл `while (condition) { ... }`;
- цикл `for (initializer; condition; step) { ... }`;
- инструкция `break;` или `continue;`;
- инструкция возврата `return expression;` или `return;`;
- вложенный блок `{ ... }`;
- выражение, после которого стоит точка с запятой.

Ветви условной инструкции и тела циклов всегда являются блоками в фигурных скобках. Инициализатор цикла `for` - это объявление переменной без точки с запятой или выражение; шаг - выражение. Все три части цикла `for` обязательны.

Результат выражения в инструкции и в шаге цикла `for` отбрасывается, но входящие в него присваивания и вызовы функций выполняются.

### Выражения

Выражение состоит из литералов, имён переменных, операций, присваиваний, круглых скобок и вызовов функций. Идентификатор, после которого стоит `(`, обозначает вызов функции, остальные идентификаторы в выражении обозначают переменные.

Присваивание `name = expression` записывает значение правой части в переменную и само имеет это значение. Присваивания можно вкладывать: `a = b = c` означает `a = (b = c)`.

### Операторы: приоритет и ассоциативность

Операторы с большим номером приоритета выполняются раньше операторов с меньшим номером.

| Приоритет | Оператор | Назначение | Ассоциативность |
| --- | --- | --- | --- |
| 8 | `-`, `!` (унарные) | Смена знака числа, логическое отрицание | Правая |
| 7 | `*`, `/`, `%` | Умножение, деление, остаток от деления | Левая |
| 6 | `+`, `-` (бинарный) | Сложение и вычитание | Левая |
| 5 | `<`, `<=`, `>`, `>=` | Сравнение чисел | Левая |
| 4 | `==`, `!=` | Проверка равенства | Левая |
| 3 | `&&` | Логическое "и" | Левая |
| 2 | `\|\|` | Логическое "или" | Левая |
| 1 | `=` | Присваивание | Правая |

Круглые скобки позволяют изменить порядок операций. Вызов функции с результатом можно использовать как операнд. Унарный плюс не поддерживается.

### Типы операндов

| Операция | Типы операндов | Тип результата |
| --- | --- | --- |
| `+`, `-`, `*`, `/` | два `int` или два `float` | тип операндов |
| `%` | два `int` | `int` |
| унарный `-` | `int` или `float` | тип операнда |
| `<`, `<=`, `>`, `>=` | два `int` или два `float` | `bool` |
| `==`, `!=` | два операнда одного типа | `bool` |
| `&&`, `\|\|` | два `bool` | `bool` |
| `!` | `bool` | `bool` |
| `=` | переменная и значение того же типа | тип переменной |

### Области видимости

Области видимости лексические. Тело функции, каждый вложенный блок и каждый цикл `for` образуют область видимости. Параметры функции принадлежат области её тела. Переменная из инициализатора цикла `for` принадлежит области цикла и видна в условии, шаге и теле цикла; тело цикла является вложенной областью.

Переменная видна от конца своего объявления до конца блока или цикла `for`, в котором она объявлена, включая вложенные области. Инициализатор вычисляется до создания переменной и не видит объявляемую переменную. Инициализация обязательна, поэтому неинициализированных переменных нет.

В одной области видимости имена переменных и параметров не повторяются. Во вложенной области можно объявить переменную с именем внешней переменной или параметра; до конца этой области новая переменная перекрывает внешнюю.

Функции объявляются только на верхнем уровне программы и видны во всей программе независимо от порядка объявления. Функция может вызывать себя и другие функции. Тело функции видит только свои параметры и переменные, но не переменные других функций.

Имена функций и имена переменных находятся в разных пространствах имён, поэтому переменная может называться так же, как функция.

### Правила проверки

Нарушение любого из правил является ошибкой проверки:

- в программе ровно одна функция `main`; у неё нет параметров, её результат `void`, и её нельзя вызывать;
- имена пользовательских функций не повторяются и не совпадают с именами встроенных функций;
- имена параметров одной функции не повторяются;
- каждая используемая переменная объявлена и видна в месте использования;
- вызываемая функция объявлена в программе или является встроенной, а число аргументов совпадает с числом её параметров;
- вызов функции с результатом `void` является всем выражением инструкции или шага цикла `for`; скобки вокруг такого вызова допустимы;
- левый операнд присваивания является именем переменной, возможно в круглых скобках;
- типы операндов соответствуют таблице "Типы операндов";
- тип инициализатора совпадает с типом объявленной переменной, тип аргумента - с типом параметра;
- условие инструкции `if` и циклов `while` и `for` имеет тип `bool`;
- `break` и `continue` находятся внутри тела цикла той же функции;
- `return` с выражением допускается только в функции с результатом, а `return` без выражения - только в функции с результатом `void`; тип выражения совпадает с типом результата функции;
- каждый путь выполнения тела функции с результатом заканчивается `return`.

Путь выполнения считается завершённым инструкцией `return`, если она стоит в теле или вложенном блоке, либо если обе ветви условной инструкции с `else` завершаются `return`. Циклы при этом не учитываются: после цикла функция с результатом должна содержать `return`.

### Правила вычислений

Диапазоны значений типов указаны в разделе "Типы", диапазон целочисленных литералов - в разделе лексики.

Деление `int` целочисленное, дробная часть отбрасывается в сторону нуля: `7 / 2` даёт `3`, а `-7 / 2` даёт `-3`. Остаток от деления имеет знак делимого: `7 % 3` даёт `1`, а `-7 % 3` даёт `-1`. Деление и остаток от деления на ноль и выход результата любой операции за диапазон `int` являются ошибками выполнения.

Операции над `float` выполняются по правилам IEEE 754 с округлением до ближайшего значения. Деление на ноль и результат, который не помещается в тип `float`, являются ошибками выполнения. Числа сравниваются по значению; `0.0` и `-0.0` равны.

Операнды бинарных операций и аргументы функций вычисляются слева направо. Каждый аргумент вычисляется один раз. В присваивании сначала вычисляется правая часть.

Логические операции вычисляются по короткой схеме: если левый операнд `&&` равен `false` или левый операнд `||` равен `true`, правый операнд не вычисляется, а результатом является значение левого операнда.

Условная инструкция вычисляет условие и выполняет первую ветвь, если оно равно `true`, иначе выполняет ветвь `else`, если она есть.

Цикл `while` вычисляет условие перед каждым шагом и выполняет тело, пока условие равно `true`. Цикл `for` один раз выполняет инициализатор, затем перед каждым шагом вычисляет условие и, пока оно равно `true`, выполняет тело и шаг.

`break` завершает ближайший цикл, внутри которого находится. `continue` завершает текущий шаг ближайшего цикла: цикл `while` переходит к вычислению условия, а цикл `for` - к выполнению шага.

При вызове пользовательской функции её параметры получают значения аргументов. Параметры передаются по значению: присваивание параметра не изменяет переменные вызывающей функции. Тело выполняется в новой области видимости. `return` с выражением завершает функцию и возвращает значение выражения, в том числе изнутри цикла. Функция с результатом `void` завершается инструкцией `return;` или после последней инструкции тела.

Ошибка выполнения прекращает программу; уже выполненные ввод и вывод сохраняются. Нехватка стека при разборе, проверке или выполнении глубоко вложенных конструкций и вызовов является ошибкой.

### Встроенные функции

| Функция | Результат и действие |
| --- | --- |
| `print(value: int): void` | Выводит целое число в десятичной записи и завершает строку |
| `printFloat(value: float): void` | Выводит число с плавающей точкой и завершает строку |
| `readInt(): int` | Читает одну строку стандартного ввода и возвращает целое число |
| `readFloat(): float` | Читает одну строку стандартного ввода и возвращает число с плавающей точкой |
| `abs(value: int): int` | Возвращает модуль числа |
| `min(left: int, right: int): int` | Возвращает меньшее из двух чисел |
| `max(left: int, right: int): int` | Возвращает большее из двух чисел |
| `toFloat(value: int): float` | Возвращает то же число в типе `float` |
| `toInt(value: float): int` | Отбрасывает дробную часть числа в сторону нуля и возвращает результат в типе `int` |

`readInt` и `readFloat` читают число без приглашения ко вводу. В строке допускаются начальные и конечные пробелы и табуляции и необязательный знак `+` или `-`. Для `readInt` после знака следуют десятичные цифры от `0` до `9`. Для `readFloat` после знака следуют десятичные цифры, за которыми может стоять точка и хотя бы одна цифра дробной части. Ведущие нули допускаются. Пустая строка, неверная запись числа, конец ввода до получения строки и число вне диапазона типа являются ошибками выполнения.

`printFloat` выводит число в десятичной записи с точкой и ровно шестью цифрами после неё, округляя до ближайшего такого значения, а при равном удалении - к значению с чётной последней цифрой; экспоненциальная запись не используется. Например, `2.5` выводится как `2.500000`. Знак минус сохраняется, даже если отрицательное число или `-0.0` выводится как ноль: `-0.000000`.

Выход результата `abs` или `toInt` за диапазон `int` является ошибкой выполнения.

### Грамматика ISO EBNF

Грамматика описывает поток токенов лексера. Специальные последовательности ISO EBNF `? IntLiteral ?`, `? FloatLiteral ?` и `? Identifier ?` обозначают токены целочисленного литерала, литерала с плавающей точкой и идентификатора. Остальные терминалы записаны в кавычках. Начальное правило `program` описывает весь файл.

```ebnf
(* Программа и функции *)
program = function_declaration, { function_declaration } ;
function_declaration = "func", ? Identifier ?, "(", [ parameters ], ")", ":", result_type, block ;
parameters = parameter, { ",", parameter } ;
parameter = ? Identifier ?, ":", type ;
type = "int" | "float" | "bool" ;
result_type = type | "void" ;

(* Блоки и инструкции *)
block = "{", { statement }, "}" ;
statement = variable_declaration
    | if_statement
    | while_statement
    | for_statement
    | break_statement
    | continue_statement
    | return_statement
    | block
    | expression_statement ;
variable_declaration = variable_definition, ";" ;
variable_definition = type, ? Identifier ?, "=", expression ;
if_statement = "if", "(", expression, ")", block, [ "else", ( if_statement | block ) ] ;
while_statement = "while", "(", expression, ")", block ;
for_statement = "for", "(", ( variable_definition | expression ), ";", expression, ";", expression, ")", block ;
break_statement = "break", ";" ;
continue_statement = "continue", ";" ;
return_statement = "return", [ expression ], ";" ;
expression_statement = expression, ";" ;

(* Выражения: от меньшего приоритета к большему *)
expression = assignment_expression ;
assignment_expression = or_expression, [ "=", assignment_expression ] ;
or_expression = and_expression, { "||", and_expression } ;
and_expression = equality_expression, { "&&", equality_expression } ;
equality_expression = relational_expression, { ( "==" | "!=" ), relational_expression } ;
relational_expression = additive_expression,
    { ( "<" | "<=" | ">" | ">=" ), additive_expression } ;
additive_expression = multiplicative_expression,
    { ( "+" | "-" ), multiplicative_expression } ;
multiplicative_expression = unary_expression,
    { ( "*" | "/" | "%" ), unary_expression } ;
unary_expression = ( "-" | "!" ), unary_expression | primary_expression ;

(* Литерал, группировка, переменная или вызов функции *)
primary_expression = ? IntLiteral ?
    | ? FloatLiteral ?
    | "true"
    | "false"
    | "(", expression, ")"
    | ? Identifier ?, [ argument_list ] ;
argument_list = "(", [ expression, { ",", expression } ], ")" ;
```
