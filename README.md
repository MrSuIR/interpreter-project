# Интерпретатор языка Lait

Учебный проект по дисциплине "Теория автоматов и формальных языков".

Цель проекта - разработка интерпретатора на C# в рамках учебного курса.

## Запуск

Требуется .NET SDK 10. Команды выполняются из каталога `interpreter-project`:

```powershell
dotnet build Lait.slnx
dotnet run --project src/Interpreter --no-build -- examples/add-multiply.lait
```

Пример выводит `80`. Исходный файл передаётся единственным аргументом. Синтаксис
Lait описан в [спецификации](docs/specification.md), подготовленной до реализации
парсера. Аналог примера из задания использует `func main(): void` и `print`.

Ввод читается из stdin, результат записывается в stdout:

```powershell
'-7' | dotnet run --project src/Interpreter --no-build -- examples/input.lait
```

Результат: строки `7`, `3`, `5`. Ошибки исходного файла, разбора и выполнения
записываются в stderr; процесс немедленно завершается с кодом `1`.
Успешное выполнение возвращает `0`. Для запуска без сообщений сборки можно
использовать `dotnet src/Interpreter/bin/Debug/net10.0/Interpreter.dll <файл>`.

## Устройство

- `src/Lexemes` — существующий лексер.
- `src/Parsing` — отдельный модуль синтаксического анализа: рекурсивный спуск,
  методы `Parse...` соответствуют правилам EBNF. Инструкции VM добавляются
  непосредственно при разборе; AST и генераторы парсеров не используются.
- `src/Runtime` — стековая VM с проверкой переполнения и деления на ноль.
- `src/Interpreter` — консольная точка входа и обработка ошибок.

VM запускается только после успешного разбора всего файла, поэтому ошибки
синтаксиса не вызывают частичного ввода/вывода. При ошибке выполнения ранее
напечатанный результат сохраняется. Диагностики разбора содержат номер и вид
токена. Реализация ограничивает вложенность выражений 256 уровнями (скобки,
вызовы функций и унарные минусы), сообщая ошибку вместо переполнения стека.

## Проверка

```powershell
dotnet test Lait.slnx
```

Тесты проверяют лексер, приоритет и ассоциативность операций, вложенные вызовы,
порядок ввода, единственную точку входа, ошибки синтаксиса, переполнение,
деление на ноль и прекращение выполнения при ошибках.
